# 电脑端发送消息后自动跟随任务

CodexRemote 收到本机 `UserPromptSubmit` 用户提交事件后，按 `hostId + threadId` 选择任务，并通过现有 `codex_state` 推送任务及对话。六个快捷槽位之外的任务使用 `activeTask` 订阅。助手回复、工具事件和历史快照不会触发切换。

录音或任务操作进行中时最多等待 30 秒，只保留最新提交。等待期间手动更换任务、连接失效或服务停止会取消待切换。事件按任务、轮次和内容去重；缺少轮次时使用两秒去重窗口。提交时间早于服务启动、早于已接受事件或超过有效期的事件被忽略。时间来自 Hook 接收时刻，因此不用于证明桌面原始操作时间。

新任务的提交事件提供实际任务 ID 后，会结束旧草稿绑定流程并订阅该任务；消息仍从任务 IPC 快照取得。该流程不发送任务切换快捷键。

依赖运行中的 PC 桥接程序接收到 Hook 事件。只点击电脑任务而没有发送消息不会触发；当前 Hook 事件没有桌面窗口标识，同一桥接监听收到的本机 Codex 用户提交均适用。

验证命令：

```powershell
node test/codex-submission-follow.test.js
node test/connection-lifecycle.test.js
```

真机验收：设备停在任务 A，在电脑任务 B 发送消息；确认设备显示 B 的标题、历史和后续回复。另测新任务首条消息、六槽位之外的任务、录音期间提交以及断线重连。源码和 WebSocket 测试不能代替真机验收。
