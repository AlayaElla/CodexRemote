# Third-party notices

This helper links against [Opus](https://opus-codec.org/) through the system
`libopus` package. Opus is distributed under its BSD-style license. That
license and its notices govern libopus code distributed with a published
helper.

The bring-up build currently resolves libopus through Homebrew/pkg-config.
Before release, keep the exact libopus version, license text, architecture,
linkage mode, and corresponding notices with every redistributed app bundle.
